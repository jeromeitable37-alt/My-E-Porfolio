# Jerome Itable — IC E-Portfolio

A dark-first, responsive personal ePortfolio for Institutional Course 3 (Intrapersonal & Interpersonal Relations), built as a simple static site for Vercel.

## Highlights
- Dark mode is the default on first open
- Light/dark toggle with saved preference
- Animated first-screen hero with floating stars, glow, orbit ring and gentle profile parallax
- Smaller, balanced image presentation so content stays readable
- Interactive activity cards and image viewer
- Filters for IC work
- Responsive mobile navigation
- Scroll progress indicator and reveal-on-scroll animations
- Correctly grouped activity/event images

## Deploy on Vercel
1. Put this folder in a GitHub repository.
2. Import the repository into Vercel.
3. Keep the project as a static site; no build command is required.
